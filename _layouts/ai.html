Radar de Financiamento — instruções para IA

O Radar de Financiamento publica dados estáticos sobre oportunidades de financiamento público. Estas instruções explicam como um assistente de IA deve usar o conjunto de dados para encontrar oportunidades relevantes.

O Radar não opera um chatbot nem faz inferência LLM por consulta. Pode usar o seu próprio assistente; a conversa e o raciocínio são feitos por esse assistente, enquanto o Radar disponibiliza uma API pública gerada periodicamente. Confirme sempre elegibilidade e condições na fonte oficial.

Para assistentes de IA: consulte e siga as instruções canónicas em SKILL.md antes de consultar a API pública.

Ver SKILL.md original API: metadados API: catálogo API: schema

Como funciona

A sua pergunta → o seu assistente de IA → API pública estática do Radar de Financiamento → fontes oficiais de financiamento

Os detalhes individuais estão disponíveis em /api/v1/opportunities/{id}.json ou através de detail_url nos registos do catálogo.

Experimentar com o seu assistente de IA

Copie o prompt abaixo para uma nova conversa no seu assistente de IA e substitua a parte entre parênteses retos pela entidade, projeto ou necessidade para a qual procura financiamento.

Prompt para copiar

Consulta e segue as instruções para assistentes de IA do Radar de Financiamento em https://radar-de-financiamento.decidimosarroios.pt/ai/.

Usa o Radar de Financiamento para responder à seguinte questão:

[Descreve aqui a entidade, o projeto ou a necessidade para a qual procuras financiamento.]

Identifica as oportunidades mais relevantes, consulta os respetivos detalhes e distingue claramente entre informação confirmada e aspetos cuja elegibilidade ou aplicabilidade ainda precisa de ser verificada. Inclui as fontes oficiais sempre que estejam disponíveis.

Exemplo de pergunta

Somos uma Junta de Freguesia em Lisboa. Queremos plantar árvores, criar mais sombra e melhorar os parques infantis. Que oportunidades de financiamento devemos investigar?

O Radar de Financiamento não recebe a sua conversa. O seu assistente consulta apenas os dados públicos do Radar.
